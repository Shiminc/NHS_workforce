# NHS_workforce
The data is downloaded from https://digital.nhs.uk/data-and-information/publications/statistical/nhs-workforce-statistics.

The data used in this work is the data table 14 of NHS Workforce Statistics - June 2026 https://digital.nhs.uk/data-and-information/publications/statistical/nhs-workforce-statistics/june-2026

The nationality is matched with Foreign, Commonwealth
& Development Office country names data, although there are some discrepancies that requires manual checking. 
https://www.gov.uk/csv-preview/6a5e0ceb9e2827ee5f6d08ca/FCDO_Geographical_Names_Index_July2026.csv

The geojson used for drawing the choropleth map is taken from D3 in action code files
https://github.com/d3js-in-action-third-edition/code-files
